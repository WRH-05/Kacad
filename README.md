# Kennedy School

Starter scaffold for the Kennedy School website.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- Three locales: English, French, Arabic

## Structure

- `app/` - routes and layouts
- `content/` - structured school content extracted from the plan
- `lib/` - locale helpers and dictionary loading
- `messages/` - translation JSON files
- `styles/` - global CSS and theme tokens
